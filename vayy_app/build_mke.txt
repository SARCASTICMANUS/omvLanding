To install a React Native app directly onto your Android phone locally, you need to compile your JavaScript and native code into an **APK file** (Android Package Kit) or run a local **Development Build** directly onto your connected device.

Here is the straightforward guide to building and installing your app locally using **Expo** (the modern standard for React Native) or **Pure React Native CLI**.

---

## 📱 Method 1: Using Expo (Recommended)

If your project was initialized with Expo, you have two quick local options:

### Option A: Install directly via USB (Fastest for testing)

1. **Enable USB Debugging on your Android phone:**
* Go to **Settings > About Phone** -> Tap **Build Number** 7 times to enable *Developer Options*.
* Go to **Settings > System / Developer Options** -> Turn on **USB Debugging**.


2. **Connect your phone to your PC/Mac via USB cable.**
3. In your project terminal, run:
```bash
npx expo run:android

```


*This automatically compiles the native Android app, launches a local server, and installs the app directly onto your connected phone.*

---

### Option B: Build an installable `.apk` file locally

If you want a standalone `.apk` file that you can send to your phone or share with friends without keeping your PC connected:

1. Install EAS CLI locally:
```bash
npm install -g eas-cli

```


2. Configure your project for local APK builds:
```bash
eas build:configure

```


3. Open the generated `eas.json` file and add an `apk` profile:
```json
{
  "build": {
    "preview": {
      "android": {
        "buildType": "apk"
      }
    }
  }
}

```


4. Run the local build command:
```bash
eas build --platform android --profile preview --local

```


*Once finished, this outputs an `.apk` file on your computer. Move this file to your phone (via USB, Drive, or WhatsApp) and tap it to install.*

---

## ⚛️ Method 2: Pure React Native CLI (Non-Expo)

If you are using standard React Native without Expo:

### Option A: Run directly on a connected device via USB

1. Enable **USB Debugging** on your Android phone and plug it in.
2. Verify your PC detects the phone by running:
```bash
adb devices

```


*(You should see your phone listed under "List of devices attached")*
3. In your project root folder, run:
```bash
npx react-native run-android --mode=debug

```



---

### Option B: Build a standalone Release APK locally

To create a standalone `.apk` file that works without a running Metro bundler server:

1. **Generate the Android Release APK:** Requires Android Studio SDK.
Open your terminal in your React Native project root and navigate to the `android` folder:

```bash
cd android
./gradlew assembleRelease

```

*(On Windows Command Prompt, use `gradlew assembleRelease` without `./`)*


2. **Locate your generated APK:** Output directory.
Once Gradle finishes compiling, your ready-to-install APK will be saved at:

```text
android/app/build/outputs/apk/release/app-release.apk

```


3. **Install it on your device:** Via ADB or File Transfer.
You can transfer `app-release.apk` to your phone manually, or install it directly via terminal using ADB:

```bash
adb install android/app/build/outputs/apk/release/app-release.apk

```


---

## 🛠️ Prerequisites Checklist

If you encounter errors during local compilation, verify that:

* **Java Development Kit (JDK 17)** is installed on your computer.
* **Android Studio** is installed with the **Android SDK** and **Build-Tools** added to your system environment variables (`ANDROID_HOME`).
