# VAYY Repository

VAYY is a route-first mobility platform with a Django/PostGIS backend, React web frontend, React admin console, and Expo/React Native mobile app.

**Project documentation lives in [`docs/`](docs/README.md).** Start there for architecture, local development, APIs, operations, and component-specific guides.

- [`docs/backend/`](docs/backend/README.md) — Django API, domains, routing, real-time and background processing.
- [`docs/frontend/`](docs/frontend/README.md) — passenger/driver web application.
- [`docs/admin/`](docs/admin/README.md) — administration console.
- [`docs/vayy_app/`](docs/vayy_app/README.md) — Android/iOS Expo app.
- [`docs/architecture/`](docs/architecture/system-overview.md) — architecture, project mandates and scalability notes.

Keep `GEMINI.md` and the scoped `AGENTS.md` files at their original locations because coding tools discover them as project instructions. Legal terms-of-service documents remain alongside the assets that consume them.
